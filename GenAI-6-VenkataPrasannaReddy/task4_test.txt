Defensive Coding (The Core Goal): Exception handling is a programming mechanism used to intercept and manage runtime errors (like dividing by zero, missing files, or network drops) so that your application can recover gracefully instead of abruptly crashing.
The Guard Block (try): You place code that is risky or prone to failing inside a try block. Python monitors this block line-by-line; if an error occurs, it instantly halts execution of that block and jumps to the error handler.
The Error Handler (except): The except block catches specific errors thrown by the try block. It allows you to remedy the situation (e.g., provide a fallback value, print a helpful message, or log the bug) and keep the rest of the application running smoothly.
The Cleanup Guarantee (finally): The finally block always executes, regardless of whether your code succeeded or crashed. It is the designated space to release expensive external system resources, such as closing file streams, disconnecting database pools, or breaking API connections.
The Trigger (raise): Developers use the raise keyword to intentionally trigger an exception when business logic requirements are violated (e.g., throwing a custom InvalidAgeError if an input value is under 18).
