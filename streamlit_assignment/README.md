In this streamlit assignment, I have created four files, which are as follows:
1. app_basic.py : This file contains the basic structure of a streamlit app, which includes a title, a header, and a text input box. The user can enter their name in the text input box, and the app will display a greeting message with the user's name.
2. app_dashboard.py : This file contains a dashboard app, which describes monthly sales data. The app displays a bar chart of the sales data, and the user can select the month for which they want to see the sales data.
3. app_discount.py : This file contains a discount calculator app, which calculates the discounted price of a product based on the original price and the discount percentage. The user can enter the original price and the discount percentage, and the app will display the discounted price.
4. app_product_form.py : This file contains a form app, which allows the user to enter their product information, such as product name, category. On clicking add product will get a success message with the product name and category. The user can also select the product category from a dropdown list.

To run the streamlit app, you can use the following command in the terminal:
```streamlit run <file_name>.py```
